# iOS 26-style Home Screen icon attribution

Nakula Phone uses iOS 26 Liquid Glass-inspired icon artwork from the
open-source iOS Icon Pack project:

https://github.com/SysAdminDoc/iOSIconPack
https://sysadmindoc.github.io/iOSIconPack/

Source images are loaded from the repository's public
`app/src/main/res/drawable-xxxhdpi/ios26_lg_*.png` files.
These are community-made approximations of the Apple iOS 26 appearance,
not Apple-issued artwork.

Mapped apps: Photos, Notes, Calculator, Mail, Settings, Clock, Phone,
Safari, Messages, Music, and Files. Calendar deliberately keeps its
interactive in-story date, and Contacts retains its existing custom icon.
The original home icons remain in the UI as automatic image-load fallbacks.
